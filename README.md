# 离线语音输入（Audio Input）

一个**只有语音**的安卓输入法：平时用 Gboard 等键盘打字，要说话时切到它，说完一键切回。
识别全程离线，在骁龙 8 Gen 2（SM8550）和 8 Gen 3（SM8650）上跑在 NPU 里，又快又省电；其他手机用 CPU 模型。

识别部分源自 [capsopasme/fcitx5-android](https://github.com/capsopasme/fcitx5-android) 的 `voice-input` 分支，
去掉了 fcitx5 本体，单独做成一个轻量的语音输入法。

## 使用

1. 安装 [Releases](https://github.com/capsopasme/audio_input/releases) 里的 APK（仅 arm64-v8a）。
2. 打开「离线语音输入」，按「开始使用」里的 4 步：启用输入法 → 麦克风权限 → 下载模型 → 试一试。
3. 平时在 Gboard 里通过地球键 / 系统的输入法切换按钮切到「离线语音输入」，键盘弹出即开始聆听，
   停顿后整句上屏；左上角的键盘按钮切回上一个输入法（长按可选择输入法）。
   还在识别最后一句时点切回，会等这句上屏再切（再点一次立即切）。

面板：

```
[⌨ 切回]        状态                  [⚙]
          实时识别的文字（灰色为已上屏）
 ，  。  ？  ！  、  ：
[↶ 撤销上一句] [⌫]   ( 🎤 )   [空格] [↵ 回车/发送/搜索]
```

## 模型

| 模型 | 运行位置 | 说明 |
|---|---|---|
| SenseVoice · 高通 NPU（8 Gen 3） | SM8650 NPU（HTP v75） | 8 Gen 3 上默认推荐。QNN 2.40 预编译模型（20 秒输入窗口），中英粤日韩，自带标点 |
| SenseVoice · 高通 NPU（8 Gen 2） | SM8550 NPU（HTP v73） | 8 Gen 2 上默认推荐。同上，为 SM8550 编译 |
| SenseVoice · CPU | 任意 arm64 | 后备；NPU 出问题时自动改用它（需已下载） |
| Qwen3-ASR 0.6B · CPU | 任意 arm64 | 最准，约 880 MB，每句 1–2 秒，不做实时预览 |

NPU 模型是按芯片编译的，设置里只列出本机芯片对应的那一个（按 `Build.SOC_MODEL` 判断），导入别的芯片的 NPU 模型包会被拒绝。
模型在设置里下载（支持 GitHub 加速前缀，移动网络下会先确认），也可以导入在电脑上下好的 sherpa-onnx `.tar.bz2`。
当前选中的模型还没装时，下载或导入的模型会自动成为使用中的模型；删除使用中的模型时自动改用另一个已安装的。
存放在应用私有目录，卸载即清除。

## 稳定与省电的设计

- **识别在独立进程 `:voice`**：QNN / onnxruntime 的致命错误会直接 `exit()`，隔离后键盘本身不受影响。
  加载 NPU 模型前写标记文件，若进程在加载中崩溃，下次自动改用 CPU 模型；被系统回收内存、强行停止或手机重启
  打断的加载不算崩溃（Android 11+ 按系统记录的进程结束原因判断）。会话中连续崩溃两次也会改用 CPU，
  这个状态跨越输入法的切换保留。设置里对 NPU 模型点「自检」可强制重试（通过即恢复 NPU），应用更新后也会重新尝试。
- **看门狗**：模型加载或收尾超时（例如 DSP 卡死）会结束识别进程并提示，不会让麦克风一直开着；
  加载中途停止聆听时仍按加载时限计算，不会误杀正常的慢加载。设置里的自检同样有超时。
- **录音只在键盘进程、只在键盘可见时**：键盘隐藏、切换输入框、切走输入法都会立即释放麦克风；
  一段时间（默认 20 秒）没识别出内容自动停止；另有兜底超时。
- **没有前台服务、没有唤醒锁**。键盘隐藏 10 秒后解除绑定，识别进程变成缓存进程被系统冻结，
  模型留在内存里不耗电，内存紧张时由系统回收。
- 麦克风光圈只在音量跨档时重绘一帧；实时预览按解码耗时自动限频，可关闭。
- 音频服务重启 / 换耳机导致录音中断时自动重连；麦克风被通话或其他应用占用、或被隐私开关关闭（只收到静音）时会提示。
- 自动开始聆听只在键盘弹出或换输入框时触发；应用对同一输入框 `restartInput` 时不会把手动停下的麦克风重新打开。
- 结果只写入说话时的那个输入框：输入框变了就丢弃并提示，绝不会写进别的应用或密码框；密码框里禁用语音。
- 下载边下边解压（不额外占一份压缩包的空间），先检查剩余空间，解压完 fsync 后再原子改名就位，断电不会留下半个模型。

### ColorOS 16 相关

- Android 15+ 输入法窗口强制全面屏：面板自己按导航栏 / 手势条高度留白，背景延伸到底部。
- 原生库以解压方式安装（`extractNativeLibs=true`），NPU 的 Skel 库需要真实路径；声明了 `libcdsprpc.so`。
- 不需要自启动、后台运行、电池优化白名单等任何权限：输入法由系统绑定，识别进程只在键盘使用时运行。
- 麦克风权限由一个透明 Activity 代为申请（输入法本身不能弹权限框）。

## 给助手用（不弹键盘）

[助手（capsopasme/Assistant）](https://github.com/capsopasme/Assistant) 通过 `RecognizerBridgeService` 直接使用本应用的识别：
助手自己录音，把 16 kHz PCM 流式发过来，这里按本应用设置里的模型、语言、标点等选项识别（含 NPU 崩溃后改用 CPU 的策略）并返回结果，不需要切换输入法。
助手保持绑定时，识别进程和已加载的模型一直留在内存里，每次说话不必重新加载模型。只接受助手本身的请求。

## 构建

原生库不进仓库，CI 会自动编译。本地构建：

```sh
export ANDROID_NDK=/path/to/ndk   # r28
./scripts/prepare-native.sh       # 编译 sherpa-onnx v1.13.8（QNN=ON），下载 QNN 2.40 运行库（HTP v73 + v75）
./gradlew :app:assembleRelease
```

发版：在 Actions → Build → Run workflow 里填 `release_tag`（如 `v1.0.1`），或推送 `v*` 标签。
CI 会用仓库 secrets 里的签名密钥构建（按内容自动识别 keystore 和密码，secret 叫什么名字都行），
并创建 Release；没有可用的正式签名时拒绝发版。
